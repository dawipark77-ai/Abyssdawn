# 작업 목록 — 2026-10-15 플레이 피드백

## 확정된 결정
- **밸런스**: 1~10층 기준표 문서를 먼저 만들어 승인받은 뒤 공식·수치·서약/직업 특성을 한 번에 조정. 몬스터 공격은 ATK의 일정 %가 늘 들어가게.
- **종의 기억 묶음**: 종족 이름 대신 문양 + 숫자(기억의 갈래 I·II·III). "기억을 잃은 용사"임을 문구로 밝힘. 같은 갈래 3개로 특성을 얻으면 깨어나는 장면도 보여 줌.
- **위치 이동**: 주인공만. 인접 1칸(빈 칸이면 이동, 사람 있으면 교환), 주인공 행동 소모. 몬스터는 스스로 이동 불가(스킬로 인한 이동만).
- **층 EXP**: 계단·지도 완성 EXP 모두 없앰. EXP는 전투·함정 해제로만.
- **맵 크기**: 픽셀 던전과 비슷하게 (약 32×30칸, 방 7~9개). 참고: 원작 Level 32×32, 하수도 일반 방 4~6 + 특수 1~2.
- **보물상자**: 열기 전 확인. 함정 상자 구현. 미믹은 몬스터가 아직 없으므로 연결 자리만 준비.
- **여행 로그**: 던전 화면 아래 최근 4줄 (시간이 지나면 흐려짐, 누르면 전체 기록).

- [x] 단검 스킬을 배웠는데 상태창에 안 나옴
- [x] 동료(박쥐)가 레벨업함 → 레벨업은 주인공만
- [x] 서약&제약: 닫기 안 됨, 글씨 작음, 패스 탭 찾기 어려움, 배경 테두리 옅은 황금색
- [x] 상태창 종의 특성 눌러도 상세 안 나옴
