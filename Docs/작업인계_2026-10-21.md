## 1. 지금 게임 상태 요약 (10-19 ~ 21 작업 결과)

### 스킬
- **모든 스킬 SP 1.** "LP" 라는 말은 전부 "SP" (스킬 포인트). 트리 노드는 `LoreTreeStyle.StyleNode` 가 실행 시 `requiredSkillPoints = 1` 로 고정 (씬에 남은 2·3 값 무시).
- **트리 이름 "~학"**: 검술학·단검학·도끼학·방패학·격투학·전쟁학·보급학·보조학 (`SceneLabelsKo` 표 + 스킬 설명 꼬리표 `[격투학 · 공격]` 등). 전투학·신성·탐험은 그대로. 스킬 이름 "기초 검술"은 그대로.
- **검술학 트리 (16개)**: 시작 = 베기 + 기초 검술. 베기 아래 한 줄 = 강베기 · 역베기 · 만드리토 (만드리토 선행 = 베기). 만드리토 아래 리베르소. 역베기 아래 페인트(→따라 들어가기)·자루치기. 기초 검술 아래 날카로운 칼날(→자리 옮기기→전진 찌르기, 칼등치기)·황소 자세(→받아넘기기→검의 리듬).
  - 리베르소: 전열 2명 왼→오, 마지막 맞은 적에게 40% 역베기. HP 12%.
  - 자루치기: 1명 기절 3턴, 같은 적 70→60→50→40→30% 뒤 면역. HP 5%.
  - 칼등치기: 아군 = 명중·치명·회피·STR +5%. 적 = HP 30% 미만만, ATK 50%, 1 HP 아래로 안 떨어짐 → 다음 차례 항복·도주 (골드 ×1.5, 소지품 30%, 계단 35%, 다른 적 사기 하락). HP 3%, 쿨 2.
- **자연 회복** (`EX_NaturalRecovery`, key "Natural Recovery", 상시): 12걸음마다 HP 1. 기본 기능에서 뺐음 — 이 스킬을 배워야만 작동. **어느 트리에도 노드 없음 (위치 미정).**
- 새 아이콘: 기본 검술 `BasicSwordsmanship_icon02`, 베기 `Slash_icon02` (귀퉁이 흰 바탕 투명 처리, 베기 데이터 2벌 모두 연결).

### 스킬 트리 화면 (`LoreTreeStyle.cs` · `LoreTreeLayout.cs` · `SkillTreeLinks.cs` · `SkillPositionIndicator.cs`)
- 패널이 화면 좌우·위 끝까지, 아래는 캐릭터 카드 윗선 (`FillScreen`). 컨테이너 상자(금테·어두운 바탕) 없음 — 스킬과 스킬 세트가 맨 뒤 배경 위에 바로.

- 무기 아이콘 줄: 이름 없음, 작게. 트리 제목: 가로 배경판 + 글자 36 고정 (자동 크기 끔 — 한글화가 켠 자동 크기 때문에 트리마다 크기가 달랐음).
