1. 땀샘: "유일한 전신 냉각 시스템" 
Species : Human
보정: HP +10% / 마력 -1 (마력을 보존할 '마력막' 대신 '땀구멍'이 뚫려 있는 피부)
다른 종족(오크, 엘프 등)도 땀을 흘릴 수 있지만, 그들은 주로 개나 고양이처럼 특정 부위 혹은 마법적인 체온 유지에 의존한다고 설정해 봅시다.
차별점: 인간은 전신 피부 어디서나 땀이 터져 나옵니다.
게임적 해석: 오크는 전투가 길어지면 근육이 과열되어 폭주하거나 쓰러지지만, 인간은 땀을 흘리며 끝까지 냉정함을 유지합니다.



2. 턱끝 (Mental Protuberance): "유일한 돌출형 턱"
해부학적으로 **'턱끝 뼈(Chin)'**가 툭 튀어나온 생물은 지구상에 호모 사피엔스뿐입니다. 고릴라나 침팬지는 물론, 네안데르탈인조차 턱이 안으로 깎여 있습니다.

차별점: 엘프나 오크의 턱은 매끈하거나 안으로 들어간 '경사형'인 반면, 인간만 유독 턱뼈가 앞으로 돌출되어 얼굴의 하단을 지탱합니다.

게임적 해석: 이 돌출된 뼈는 투구의 끈을 고정하고 충격을 분산하는 최적의 지지대입니다.

보정: 방어 +1 / 민첩 -1 (머리 하단이 무거워 회전 시 관성이 생김)

3. 하얀 공막: "의도적 노출"
동물계에서 흰자위는 '약점'입니다. 내가 어디를 보는지 들키기 때문이죠.

차별점: 다른 종족들은 눈동자가 눈 전체를 차지하거나(엘프), 공막이 어두운 색(오크)이라 시선을 숨깁니다. 오직 인간만이 **"나 여기 보고 있어!"**라고 광고하듯 하얀 흰자위를 드러냅니다.

게임적 해석: 이건 사회적 동물인 인간이 **'협력'**하기 위해 진화시킨 장치입니다.

보정: 행운 +2 / 방어 -1 (동료와 호흡이 잘 맞지만, 적에게 다음 수를 읽힘)

4. 붉은 입술: "외부로 드러난 점막"
인간의 입술은 입 안의 점막이 밖으로 말려 나와 뒤집힌 형태입니다. 다른 동물은 입술이 피부와 같은 색이며 안으로 말려 있습니다.

차별점: 엘프나 오크의 입은 단순히 '입구'라면, 인간의 입술은 **'정교한 발성 장치'**입니다.

게임적 해석: 인간은 이 붉고 유연한 입술 덕분에 가장 복잡한 언어와 주문을 구사합니다.

보정: 마력 +1 / 공격 -1 (섬세한 입 구조 때문에 깨물거나 들이받는 위력은 감소)

5. 유연한 어깨: "투척을 위한 진화"
유인원은 팔을 머리 위로 올릴 순 있어도, 인간처럼 야구 선수처럼 뒤로 젖혔다가 채찍처럼 휘두르는 어깨 구조는 없습니다.

차별점: 다른 종족의 어깨가 '매달리기'나 '내려치기'에 특화되었다면, 인간의 어깨는 **'원거리 투척'**에 올인했습니다.

게임적 해석: 인간은 도구(무기)를 다룰 때 가동 범위가 가장 넓습니다.

보정: 공격 +2 / 방어 -1 (유연한 만큼 관절이 불안정함)


1. 오크 (Orc): 과부하를 견디는 전투 병기오크는 근섬유와 에너지 소모를 극대화한 종족입니다.

 1. 돌출된 거대 엄니 (Giant Tusks): 아래턱 근육과 연결되어 씹는 힘과 목 근육을 강화합니다.득: 공격 +2 / 실: 마력 -1 (정교한 마법 주문 발음 불가)
 2. 두꺼운 피하 지방과 각질층 (Thick Dermal Layer): 외부 충격을 흡수하는 천연 갑옷입니다.득: 방어 +2 / 실: 민첩 -1 (피부가 뻣뻣하여 유연성 부족)
 3. 적혈구 과다 생성 (Polycythemia): 근육에 산소를 즉각 공급해 폭발적인 힘을 냅니다.득: 공격 +1, HP +10% / 실: 행운 -1 (혈압 상승으로 인한 다혈질적 판단)
 4. 역방향 무릎 관절 (Digitigrade-like Stance): 폭발적인 돌진력을 위해 아킬레스건이 매우 짧고 굵습니다.득: 공격 +1 (돌격 위력) / 실: 민첩 -1 (방향 전환의 어려움)
 5. 빛 반사 방지 피부 (Matte Skin): 땀샘이 거의 없어 피부가 건조하고 빛을 흡수합니다.득: 민첩 +1 (은신/기습) / 실: HP -10% (체온 조절 실패로 장기전 불리)

2. 엘프 (Elf): 마력 감응형 초정밀 생물엘프는 공기 중의 에너지를 감지하고 반응하는 데 최적화되어 있습니다. 

 1. 마력 감응 뾰족귀 (Mana-sensitive Pointed Ears): 미세한 마력의 파동을 소리로 치환해 듣습니다.득: 마력 +2 / 실: 방어 -1 (소음이나 마력 폭주에 극도로 취약)
 2. 단일색 홍채와 투명 공막 (Mono-color Sclera): 흰자위가 없어 시선 추적이 불가능하며 빛을 더 많이 받아들입니다.득: 민첩 +2 (초정밀 시야) / 실: 행운 -1 (동료와의 비언어적 협동 불가)
 3. 경량화된 골격 (Pneumatic Bones): 뼈 내부가 새처럼 비어 있어 무게를 줄였습니다.득: 민첩 +1 / 실: HP -10% (골절에 매우 취약함)
 4. 정전기 유도 모발 (Electro-static Hair): 머리카락이 안테나 역할을 하여 원거리의 기척을 감지합니다.득: 행운 +1, 민첩 +1 / 실: 방어 -1 (전기/마법 자극에 예민함)
 5. 협소한 위장 (Minimalist Digestion): 최소한의 영양소와 마력으로 생존합니다.득: 마력 +1 / 실: 공격 -1 (물리적 근력 저하)

3. 호빗 (Hobbit): 저중심의 기회주의자호빗은 작고 낮은 신체를 이용해 위협을 피하고 이득을 취하는 데 특화되었습니다.
 
 1. 발바닥의 두꺼운 천연 가죽 (Calloused Foot-soles): 신발 없이도 소음 없이 이동하며 지면의 진동을 읽습니다.득: 민첩 +2 / 실: 공격 -1 (무거운 무기 사용 시 지지력 부족)
 2. 극대화된 후각 수용체 (Enlarged Olfactory Bulbs): 음식, 위험, 금속의 냄새를 예민하게 맡습니다.득: 행운 +2 / 실: 마력 -1 (강한 마법 향취에 구역질 반응)
 3. 낮은 무게 중심과 짧은 대퇴골: 상체보다 하체가 발달해 급격한 방향 전환이 가능합니다.득: 민첩 +1, 방어 +1 / 실: 공격 -1 (리치(Reach)가 매우 짧음)
 4. 빠른 당분 연소 (Rapid Sugar Metabolism): 위급 상황에서 아드레날린을 폭발적으로 사용합니다.득: 행운 +1 / 실: HP -10% (금방 허기를 느껴 스테미나 급감)
 5. 정교한 원추세포 (Developed Cones): 색깔과 질감을 구분하는 능력이 탁월해 기계 장치를 잘 다룹니다.득: 행운 +1 / 실: 방어 -1 (화려한 시각적 마법에 쉽게 실명됨)

4. 드워프 (Dwarf): 고밀도 중압력 골격드워프는 좁은 공간에서 강한 압력을 견디며 일하도록 설계된 '바위' 같은 종족입니다.

 1. 고밀도 칼슘 골격 (High-density Bone): 인간보다 뼈의 밀도가 3배 높아 웬만한 타격은 무시합니다.득: 방어 +2 / 실: 민첩 -2 (몸이 너무 무거워 점프나 수영 불가)
 2. 광석 감지 수염 (Ore-sensing Whiskers): 수염 뿌리가 미세한 공기 흐름과 암반의 진동을 감지합니다.득: 행운 +1, 마력 +1 (대지 마법) / 실: 민첩 -1 (수염이 걸리적거림)
 3. 확장된 흉곽과 폐 (Expanded Ribcage): 산소가 희박한 지하에서도 충분한 호흡을 유지합니다.득: HP +20% / 실: 민첩 -1 (상체가 비대해 유연한 동작 불가)
 4. 적외선 감지 망막 (Infrared Retinas): 어둠 속에서 열원을 추적합니다.득: 공격 +1 (어둠 속 정밀 타격) / 실: 행운 -1 (밝은 지상에서 시야 혼동)
 5. 두꺼운 전완근과 강력한 악력 (Bulky Forearms): 손목 힘이 종족 중 가장 강해 무거운 망치도 한 손으로 휘두릅니다.득: 공격 +2 / 실: 마력 -1 (섬세한 마법 도구 조작 시 파손 위험)
