Combat Arts 전투기술

전투기술(Combat Arts) 1티어 스킬 5개

1) Evasive Stance – 회피 자세 
Usage Type: Active Maneuver
Cost: HP 또는 “기력” 5% / MP 0 (에너지 소모형)
Effect:
2턴 동안 회피율 +15%, 받는 데미지 -10%
앞열 위치 시 회피 +5% 추가 (총 +20%)
이 효과 동안, 자신의 공격 스킬 데미지 -15% (수비 자세)
얻는 것: 생존, 집중 회피
잃는 것: 공격 기회/딜 손해
스탯 의존: Agility
던브레이크(0.8%): 이번 턴에 들어오는 첫 물리 공격 완전 회피 + 반격(공격 1회 50% 위력)

2) Advancing Strike – 전진 타격
Usage Type: Active Attack / Maneuver
Cost: HP 4% / MP 0
Target: 단일 적, 사용 후 전열로 전진
Effect:
데미지: 공격력 × 1.2 ~ 1.5
명중 성공 시, 자신 회피율 +10% (1턴)
적에게 “밀려남” 1칸 효과가 있는 전열/후열 시스템으로 확장 가능(일단은 데미지+버프로만 구현해도 됨)
얻는 것: 공격 + 포지션 잡기
잃는 것: HP 소모, 위험한 전열로 들어감
스탯 의존: Attack, Agility
던브레이크(1.0%): 크리티컬 확정(또는 크리티컬 확률 +50%) + 자신에게 추가 회피 +10% (총 +20%)

3) Counter Guard – 반격 태세
Usage Type: Active Maneuver (Defend 계열)
Cost: HP 3% / MP 0
Effect (2턴):
자신이 공격을 받을 때마다, 50% 확률로 받는 피해 -50%
발동 시, 공격자에게 기본 공격 50% 위력으로 반격 1회
한 턴에 최대 2회까지 반격
얻는 것: 탱킹 + 반격 딜
잃는 것: 효과 동안 자신의 능동 공격 스킬 사용 불가(일반 공격만 가능) 같은 제약 줄 수도 있음
스탯 의존: Defense, Attack
던브레이크(0.8%): 다음에 들어오는 공격 1회는 완전 무효화 + 풀 데미지 반격(100%)

4) Tactical Roll – 전술 구르기
Usage Type: Active Maneuver (이동 회피)
Cost: HP 3% / MP 0
Effect:
즉시 단일 적의 공격을 1회 회피 (적이 이미 준비한 공격/다음 근접 공격)
자신 위치 변경: 전열 ↔ 후열 스왑 (전열/후열 시스템 적용 가정)
1턴 동안 상태 이상 저항 +20%
얻는 것: 위험한 자리에서 후퇴, 혹은 후열에서 전열로 진입하면서 회피
잃는 것: HP 소모, 사용 턴에는 공격을 못 할 수도 있음(밸런스 보고 결정)
스탯 의존: Agility
던브레이크(1.0%): 스왑 직후 추가 행동 게이지 +20% (즉, 조금 더 빨리 다음 턴이 옴)

5) Focused Lunge – 집중 찌르기
Usage Type: Active Attack
Cost: HP 6% / MP 0
Target: 단일 적 (앞열 우선, 없으면 후열)
Effect:
데미지: 공격력 × 1.7 ~ 2.0, 방어 무시 +10%
자신의 현재 HP가 50% 미만이면 추가로 크리티컬 확률 +20%
얻는 것: 방어 뚫는 강력한 피니시 기술
잃는 것: HP 소모, 사용 후 1턴 동안 받는 피해 +10% (숨 고르기)
스탯 의존: Attack
던브레이크(1.2%): 해당 공격이 확정 크리 + 추가 방어 무시 +10% (총 20%)

6) Rallying Shout – 격려의 함성
Usage Type: Active Support / Shout
Cost: HP 5% / MP 3
Effect (파티 전체, 2턴):
Attack +5%, Agility +5%
공포/정신 계열 디버프 저항 +20%
얻는 것: 턴 시작 전에 팀 전체 버프, 돌입 타이밍용
잃는 것: 사용자 HP/MP 소모, 스스로는 이 턴에 공격 못할 수도 있음(밸런스에 따라)
스탯 의존: Magic 또는 Luck (리더십/정신력 느낌)
던브레이크(0.8%): 이 턴에는 버프 수치 2배 (Attack/AGI +10%)
