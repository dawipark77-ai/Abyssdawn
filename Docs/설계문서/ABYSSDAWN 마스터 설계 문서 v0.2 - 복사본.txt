🗡️ 단검 트리 (Dagger Lore)
정체성: 선제, 듀얼 특화, 다중타격, 급소. 독/상태이상 없음. 순수 기동성.
출혈 수치: Max HP 1.5% / 턴, 2턴

1. 신속한 손놀림 (Flickering Blade)

Type: Passive
Effect: 단검 장착 시 턴 순서 +5. 듀얼 장착 시 첫 타 명중하면 두 번째 타격 명중률 +15%
대가: 단검 외 무기로 변경 시 1턴 공격력 -10%

2. 급소 파고들기 (Vital Strike)

Type: Passive
Effect: 후열에서 전열 공격 시 데미지 +10%. 적 HP 75% 이상일 때 크리티컬 +15%
대가: 없음 (조건 자체가 대가)

3. 그림자 베기 (Shadow Slash)

Type: Active / Attack, Cost HP 4%
Effect: × 1.3. 명중 시 적 방어 -8% (2턴). 듀얼 장착 시 즉시 두 번째 단검 추가 × 0.5
대가: 전열에서 사용 시 데미지 -15%

4. 연속 찌르기 (Flurry Stab)

Type: Active / Attack, Cost HP 5%
Effect: 3타 연속. 각 × 0.5. 각 타격 독립 크리티컬 판정. 3타 모두 명중 시 마지막 타격 × 1.5 추가
대가: 사용 후 1턴 방어 -10%

5. 칼날 춤 (Blade Dance)

Type: Active / Maneuver, Cost HP 3%
Effect: 이번 턴 첫 번째 근접 공격 회피 +25%. 회피 성공 시 즉시 반격 × 0.7
대가: 원거리 공격에 효과 없음. 회피 실패 시 반격 없음

6. 상처 벌리기 (Rend Wound)

Type: Active / Attack, Cost HP 3%
Effect: 출혈 상태 적에게만 사용 가능. × 0.3. 출혈 지속 턴 +1 갱신. 출혈 데미지 +0.5% 추가
대가: 출혈 없는 적 사용 불가. 출혈 먼저 필요

대가: 같은 종 듀얼 시 발동 안 됨. 패시브 선택은 전투 전 고정

대가: 전열 한정. 후열 적 행동에 반응 불가. 이 턴 추가 행동 없음

시스템 확정 정리

듀얼 시스템
장착 조건
├── 한손 무기 2개
├── 가능: 검/단검/도/도끼/망치/버클러 제외 한손 전체 조합
└── 불가: 대검 및 양손으로 잡는 모는 무기/창/폴암/활/쇠뇌/도(카타나) (양손 or 원거리)
    방패+한손 = 듀얼 아님, Shield 빌드

타격 구조
├── 한손 단일: 1타 × 1.0
└── 듀얼: 4타 × 0.35 = 총 1.4
    각 타격 독립 명중 판정
    각 타격 독립 크리티컬 판정

트리 적용
├── 양쪽 무기 트리 패시브/액티브 100% 사용 가능
├── 두 트리 간 시너지는 듀얼 트리 스킬 없이 발동 안 됨
└── 듀얼 트리 = 두 무기를 하나의 흐름으로 연결하는 브릿지

상태이상 스케일
듀얼 장착 시 모든 것 × 0.35 적용

확률형 (스턴, 크리티컬 등)
└── 원본 확률 × 0.35
    예: 스턴 20% → 1타당 7%

수치형 (출혈/독 데미지)
└── 원본 수치 × 0.35
    예: 출혈 Max HP 3% → 1타당 1.05%

지속형 (턴 수)
└── 원본 턴 × 0.35, 소수점 버림
    예: 4턴 → 1타당 1턴

스택형 (파괴 스택 등)
└── 원본 스택 × 0.35, 소수점 버림
    최솟값 보장 여부 추후 결정

상태이상 중복 규칙
같은 상태이상 중복
└── 갱신 방식
    수치: 높은 쪽으로 갱신
    턴 수: 리셋 (새로 부여된 턴으로)

다른 상태이상 동시
└── 독립 적용
    각자 수치/턴 수 유지
    예: 스턴 1턴 + 출혈 1턴 동시 가능

스턴 중 지속 데미지
└── 정상 적용 (스턴이 데미지를 막지 않음)

인터럽트 시스템
공통 규칙
├── 민첩 순서상 자신이 해당 적보다 앞설 때만 발동 가능
├── 발동 시 자신의 그 턴 행동권 전체 소모
├── 적도 동일하게 플레이어 행동 끊기 가능
└── 발동 조건 미충족 시 HP 소모 없음

창 — 선제 견제
├── 발동 조건: 전열 적 공격 행동 선언 시
├── 타겟: 자동 (공격한 적)
├── 배율: × 0.8
└── 포지션: 전열 한정

폴암 — 후열 압제
├── 발동 조건: 후열 적 공격 행동 선언 시
├── 타겟: 자동 (공격한 적)
├── 배율: × 0.6
└── 포지션: 후열 한정

활 — 견제 사격
├── 발동 조건: 없음 (수동 지정)
├── 타겟: 전열/후열 무관 단일 수동 지정
├── 배율: × 0.6
└── 포지션: 전체

출혈 수치 차별화
단검 출혈
├── 데미지: Max HP 1.5% / 턴
├── 지속: 2턴

물리 상태이상과 마법 상태이상 so설정


SO는 하나로 유지하되 isMagical bool 필드 하나만 추가하는 거야.
StatusEffectSO
├── damagePerTurn
├── duration
├── isMagical (bool)
└── selfApplyChance (isMagical일 때만 의미 있음)
Ignite SO 하나인데 — 마법 스킬에 끼울 땐 isMagical = true, 무기에 끼울 땐 isMagical = false.
같은 SO를 물리/마법 양쪽에 쓰되 플래그로 구분. SO 수는 그대로 유지돼.
